Notable features

Flan MCP is built for fast, low-friction UI iteration between a developer and an agent.

Runtime Control

Drive the live app from tools

Call tap, enter_text, and scroll_to to execute real user flows without adding Flutter Driver instrumentation.

Widget Precision

Inspect exact widgets by coordinates

Use inspect_widget_at to get widget type, path, bounds, and source location at a screen point with much lower token cost than screenshots.

In-App Feedback

Send intent from inside the app

The overlay lets developers point at widgets, annotate issues, and provide instructions in context instead of describing UI bugs from memory.

Queued Messaging

Never lose a message

User instructions are queued with timestamps and can be consumed via get_user_message or batch-drained using process_queue.

Tight Edit Loop

Edit, hot reload, verify

After a patch, call hot_reload and re-check the same coordinates to validate behavior quickly and keep momentum high.

Tooling Fit

Works with major coding agents

Integrates with Cursor, Claude Code, Copilot, and Gemini CLI over a simple stdio MCP setup.

Recorded End-to-End Flow

Live capture of a developer annotation, agent context pickup, patch, and hot reload.

A practical feedback loop

  1. Connect to live debug session

    Copy the ws://.../ws URL from flutter run output and call connect.

  2. Wait for developer intent

    Run process_queue and consume the queued batch with real widget and screen-coordinate context.

  3. Edit, reload, verify

    Make code changes, then automatically run hot_reload. After reload, validate using inspect_widget_at on the same coordinates.

    Agent instruction: after every successful code edit, call hot_reload without waiting for a separate user prompt.
